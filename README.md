## About
This repository contains C++ programs based on Object-Oriented Programming (OOP) concepts, focusing on Inheritance.

## Programs List

### Program 1: Basic Single Inheritance
- Demonstrates inheritance using base and derived classes.

### Program 2: Protected Member Access
- Demonstrates access to protected members in a derived class.

### Program 3: Public vs Private Inheritance
- Shows the difference between public and private inheritance.

### Program 4: Multilevel Inheritance
- Demonstrates inheritance across three levels using Person, Employee, and Manager.

### Program 5: Hierarchical Inheritance
- Demonstrates multiple derived classes using a common base class.

### Program 6: Multiple Inheritance
- Demonstrates inheritance from two base classes.

### Program 7: Multiple-Inheritance Ambiguity
- Resolves ambiguity using the scope-resolution operator.

### Program 8: Constructor and Destructor Order
- Demonstrates the order of constructor and destructor execution.

### Program 9: Parameterized Base Constructor
- Demonstrates initialization of a base class using a parameterized constructor.

### Program 10: Function Overriding
- Demonstrates function overriding using virtual and override keywords.

### Program 11: Abstract Class
- Demonstrates an abstract class using a pure virtual function.

### Program 12: Virtual Base Class
- Demonstrates diamond inheritance and the use of a virtual base class.

### Program 13: Friend Class
- Demonstrates access to private data using a friend class.

### Program 14: Nested Class
- Demonstrates a class defined inside another class.

### Program 15: Mini-Project – Vehicle Rental System
- Implements a vehicle rental system using inheritance and function overriding.

### Program 16: Mini-Project – Employee Payroll System
- Implements an employee salary system using abstract classes and inheritance.
